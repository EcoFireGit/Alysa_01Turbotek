# Alysa — TurboTek Strategic Client Alignment Engine

A Next.js application built for TurboTek (MSP) to power strategic client engagement, account planning, and executive alignment.

## Overview

Alysa is an AI-powered platform that helps TurboTek account teams manage client relationships, prepare for QBRs, and align on strategic roadmaps. It surfaces account health, value paths, and executive briefing content tailored to each client.

## Key Features

- **Account Dashboard** — Portfolio-level view of all TurboTek client accounts
- **Account Detail Views** — Deep-dive per-account pages with tabbed navigation
- **QBR / Exec Brief Tab** — AI-generated executive briefing content for quarterly reviews
- **Strategic Roadmap Tab** — Client-specific roadmap aligned to TurboTek service delivery
- **Value Path** — Visual journey mapping from current state to target outcomes
- **Strategic Alignment Workspace** — Collaborative workspace for account strategy
- **Section Chat** — Contextual AI chat scoped to individual sections of an account plan

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI**: Anthropic Claude API (`@anthropic-ai/sdk`)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
